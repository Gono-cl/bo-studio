BO Studio - Portable Windows App
================================

How to run
----------
1) Keep these together in the same folder:
   - BOStudio.exe
   - _internal (folder)
2) Double-click BOStudio.exe.

Data storage (portable mode)
----------------------------
BO Studio saves data next to the executable folder:
- resumable_manual_runs\   (saved campaigns)
- data\experiments.db      (database)

This means you can rename or move the app folder and your data will stay with it.

Important
---------
- Do not move BOStudio.exe out of this folder alone.
- Do not delete the _internal folder.
- If Windows SmartScreen warns, click "More info" then "Run anyway" (if trusted source).

Sharing with others
-------------------
Share the whole folder (or a zip of it), not only BOStudio.exe.
