Documentation Map

This is the recommended structure for BO Studio documentation.

1. Quick Start

Page: home

Purpose:

  • explain what BO Studio is,

  • show where to click first,

  • link directly to the most common workflows.

2. Guided Tutorial (primary learning path)

Page: tutorial

Purpose:

  • walk a new user through one complete campaign,

  • show parameter choices and expected outcomes,

  • connect app actions to BO reasoning.

3. BO Classroom Guide

Page: classroom_guide

Purpose:

  • explain the learning path inside BO Classroom,

  • clarify Beginner vs Advanced use,

  • explain what to focus on in each module.

4. Single Objective Optimization

Page: manual_optimization

Purpose:

  • document all controls and options in the SOO page,

  • include save/resume/reuse behavior,

  • include common mistakes and troubleshooting.

5. Multi Objective Optimization

Page: multi

Purpose:

  • explain objective selection,

  • describe Pareto interpretation,

  • describe scalarization options and practical tradeoffs.

6. Experiment Database

Page: experiment_database

Purpose:

  • explain storage model,

  • searching/filtering/export,

  • how this supports reproducibility.

7. Concepts (Theory)

Page: bayesian

Purpose:

  • define Gaussian Process and Acquisition Functions,

  • explain EI/PI/LCB behavior,

  • provide practical interpretation for chemists.

8. FAQ

Page: faq

Purpose:

  • answer frequent user questions,

  • link to troubleshooting steps.

9. About

Page: about

Purpose:

  • project scope,

  • version and citation details,

  • maintainers/contact.

Navigation recommendation

For a clean docs experience, keep this menu order:

  1. home

  2. docs_map

  3. tutorial

  4. classroom_guide

  5. Single Objective Optimization (manual_optimization)

  6. Multi Objective Optimization (multi)

  7. experiment_database

  8. bayesian

  9. faq

  10. about

This order is tutorial-first and user-centered.
